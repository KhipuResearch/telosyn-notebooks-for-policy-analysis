## One Expansion State at a Time

**A Decomposition of C01, Pooled by Random Effects.**

`M01_state_replication_pooling/M01_state_replication_pooling.ipynb`

**What it shows**

- Re-estimate one design in each jurisdiction separately and treat the results as studies, with an estimate and a standard error each.
- Pool them under fixed and random effects, and say what each pooled number is the mean *of*.
- Read heterogeneity as a finding: Cochran's Q, τ², I², and the prediction interval for the effect in a state not yet seen.
- Use a funnel plot, Egger's test and leave-one-out pooling, and say what each can and cannot show with this many estimates.

**Sources** — American Community Survey (acs/acs1); KFF Medicaid expansion status  
10 provenance records committed in `M01_state_replication_pooling/provenance/`.

**Limitations**

- The state estimates are not independent, and the plan's intervals leave out the largest shared part. Every estimate is measured against the same ten never-expanded states. The plan's standard errors include only the sampling variance of the control mean; they omit the variation among the control states' own changes, whose mean is one common draw for all 25 estimates. The labelled sensitivity in the notebook sizes it from the ten control changes and adds it: the pooled interval then becomes borderline, as C01's is. That sensitivity is a plug-in from ten control states and is itself imprecise; it does not replace the plan's primary result, which stays printed.
- Per-state intervals are sampling error in each state's own rates, not intervals for that state's effect. Each state is one treated unit compared with a shared control pool; the control pool's variance and trend noise (the placebo-timing contrast shows variation of that size arises with no expansion effect) are omitted. The counts of states whose intervals exclude zero are shown with and without the shared-control variance and are not a count of states with an effect.
- Heterogeneity is not heterogeneity in the effect alone. The expansion states start from very different uninsured rates and are compared with controls that start higher; the labelled meta-regression shows how much of the spread in estimates follows each state's starting level. τ is therefore not a clean measure of heterogeneity in treatment effects (some of the baseline-linked spread may be real effect modification, which this design cannot separate from level differences), and the levels specification inherits the problem C01 handles with a log specification.
