# Data provenance

## Purpose

This repository analyses public socioeconomic data published by U.S. federal agencies and research institutions. Every retrieval a notebook makes is recorded as a provenance record committed beside that notebook: the publisher, dataset, vintage, endpoint, the request with credentials redacted, the time of retrieval, and a SHA-256 digest of the payload on the basis stated in `hash_basis`. A later retrieval that does not reproduce the digest raises rather than silently differing.

**No raw, restricted, confidential or personally identifiable data are committed.** The two HUD files under `data/hud/` are public schedules the API does not serve; their sources are recorded in the `SOURCES.md` beside them. The Zillow files `data/zillow/` names are not committed (see *Restrictions*).

## Why `hash_basis` exists

A digest only identifies content if the publisher serialises stably. Four of the publishers here do not: Census, BLS and BEA embed request-specific metadata or return rows in unstable order, so the same request yields different bytes. Twenty-five identical County Business Patterns requests produced three distinct byte digests and one row multiset. Each record therefore states the basis its digest was taken on:

| Basis | Meaning | Used for |
|---|---|---|
| `response-bytes` | the raw body | FRED, where order is data |
| `canonical-rows` | header plus sorted rows | Census ACS, CBP, BDS, where row order is not held |
| `canonical-stable-json` | key-sorted JSON with volatile fields stripped | BLS `responseTime`, BEA `UTCProductionTime` |
| `composed-digests` | ordered per-batch digests | wide ACS pulls made in batches |

## Restrictions and privacy

- **Redistribution of this repository:** not permitted; see [`LICENSE`](../LICENSE). Public visibility grants nothing.
- **Source data terms:** each publisher's terms govern its data. All sources used are public and free to access; several require a free API key, which you supply yourself (`.env.example`).
- **Zillow:** ZHVI and ZORI files are downloaded by the reader from Zillow Research and are not committed, because Zillow overwrites them in place and redistribution is not ours to grant. The notebook pins the download it used by digest and will raise on a different file.
- **Sensitive fields:** none. Every dataset is published at county, state or series level; no microdata is used.
- **Credentials:** never committed. A release gate scans every committed output for key material and the client redacts credentials from any error it raises.

## Known limitations

- Publishers that serve no prior vintage return today's values on a re-run; those retrievals are pinned by digest so a change is detected, not reproduced.
- Four of forty retrievals were not replayable at last measurement; see `docs/reproducibility.md`.
- Each notebook's *Limitations* section states what its sources cannot support for that question.
